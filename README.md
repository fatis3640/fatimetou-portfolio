# Portfolio — Fatimetou Mohamed Hseine

Portfolio statique prêt pour Vercel.

## Fichiers
- `index.html`
- `style.css`
- `script.js`

## Lancer localement
Ouvrez simplement `index.html` dans un navigateur, ou lancez un petit serveur local.

## Déployer sur Vercel
1. Créez un nouveau dépôt GitHub et ajoutez les trois fichiers.
2. Dans Vercel, choisissez **Add New > Project**.
3. Importez le dépôt GitHub.
4. Framework Preset : **Other**.
5. Cliquez **Deploy**.

Aucune dépendance ni commande de build n'est nécessaire.
